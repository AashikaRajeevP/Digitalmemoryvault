# Digital Memory Vault

**Digital Memory Vault** is a personal web application that allows users to preserve their thoughts, experiences, and special moments as digital memories and revisit them in the future.

The application works like a digital time capsule. Users can create memories, write messages to their future selves, and choose a specific date on which each memory becomes accessible. Until that date arrives, the memory remains locked, creating a sense of anticipation and making the experience of revisiting the past more meaningful.

Built using **Python and Flask**, the project combines a simple and secure user experience with date-based memory management. Each user can manage their own memories, track locked and unlocked entries, and access memories when their scheduled dates arrive.

### Key Features

- **User Authentication:** Register, log in, and manage a personal account.
- **Create Memories:** Save personal thoughts, experiences, and messages.
- **Time-Locked Memories:** Set a future date for each memory to become accessible.
- **Countdown:** See how many days remain before a locked memory can be opened.
- **Personal Dashboard:** View and manage saved memories.
- **Memory Statistics:** Track total, locked, and unlocked memories.
- **Private Memory Space:** Keep each user's memories associated with their own account.

### Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript, Jinja2
- **Database:** PostgreSQL (Neon), SQLAlchemy
- **Database Migrations:** Flask-Migrate
- **Deployment:** Vercel
